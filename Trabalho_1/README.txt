Instruções sobre o script:
Para utilizar o script de python basta colocar os arquivos no diretório "arquivos" 
(por padrão eles ja estarão lá, mas caso queira testar com arquivos de dados diferentes) 
e rodar com o comando "pyhton main.py". O script vai gerar a imagem que foi exigida no 
enunciado da atividade com o nome "curva_precision_recall.png"

Conclusão 
Após a execução do script, os melhores Thresholds são respectivamente 0.75, 0.7 e 0.65 
na resolução de 800 pixels pois seus valores de F1 são os maiores dentre todos analisados, 
e como F1 depende de que ambos os valores de Precisão e Sensibilidade sejam altos, faz com
que essa métrica seja confiável para decidir o melhor Threshold e a melhor resolução
